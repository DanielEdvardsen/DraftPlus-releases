# DraftPlus

A League of Legends champion select helper for Windows. It ranks picks and bans using lolalytics data, auto-fills from the live League client, and shows the win estimate, lane matchup, team planner, and runes and build.

## Download

Get **DraftPlus.Setup.<version>.exe** from the [latest release](https://github.com/DanielEdvardsen/DraftPlus-releases/releases/latest) and run it.

- Installs into your user folder, so no admin rights are needed.
- The installer isn't code-signed, so Windows SmartScreen may warn you the first time. Click **More info**, then **Run anyway**.
- Installing a newer version keeps your settings and cache (stored in `%APPDATA%\draftplus`).

This repository only holds the installers. The source code is private.
